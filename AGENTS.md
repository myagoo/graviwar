## Publishing changes

After each requested modification, run the relevant checks, commit and push the changes, then run `pnpm run deploy`. Build after committing so the homepage displays the published source commit. Verify the live deployment before reporting completion.

## Agent skills

### Issue tracker

Track issues in gitignored Markdown files under `.scratch/`.
Read `docs/agents/issue-tracker.md` before working with issues.

### Triage labels

Use the five default triage statuses.
Read `docs/agents/triage-labels.md` when assigning a status.

### Domain docs

Use a single-context layout.
Read `docs/agents/domain.md` before exploring the codebase.
