# Graviwar

A gravity-based space combat game built with React, Vite, and pnpm.

This project has been migrated from Create React App to Vite for faster development and better performance.

## Available Scripts

In the project directory, you can run:

### `pnpm dev`

Runs the app in development mode with Vite's fast HMR.\
Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

The page will reload instantly if you make edits.\
You will also see any lint errors in the console.

### `pnpm build`

Builds the app for production to the `build` folder.\
It correctly bundles React in production mode and optimizes the build for the best performance.

The build is minified and the filenames include the hashes.\
Your app is ready to be deployed!

### `pnpm preview`

Locally preview the production build.

### `pnpm lint`

Run ESLint to check for code quality issues.

### `pnpm deploy`

Deploy the built app to GitHub Pages.

## Features

- **Multiplayer Support**: Play locally or with others using netplay with lockstep or rollback netcode
- **Real-time Physics**: Gravity-based gameplay with black hole mechanics
- **Touch Controls**: Support for mobile devices with pinch-to-zoom
- **Performance Optimized**: Built with Vite for lightning-fast development and builds
