# Domain docs

This repo uses a single-context layout:
- CONTEXT.md at the repo root.
- Architecture decision records under docs/adr/.

Before exploring, read CONTEXT.md and ADRs relevant to the work.
If absent, proceed silently. Domain modeling creates these
documents when terminology or decisions are resolved.

Use the glossary's vocabulary when naming domain concepts.
Note real glossary gaps for domain modeling.
Explicitly flag proposals that contradict an existing ADR.
